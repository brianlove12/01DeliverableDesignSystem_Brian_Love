S1 — Foundation and Reset

This design system uses a small selective reset to create predictable sizing and typography while preserving useful browser defaults.

Reset decisions

  • box-sizing: border-box is applied globally so declared widths include padding and borders.
  • The default body margin is removed so page spacing can be controlled by the design system.
  • Images and SVG elements are prevented from overflowing their containers.
  • Form controls inherit the surrounding type system for visual consistency.
  • Default focus indicators are intentionally not removed so keyboard users retain visible interaction cues.
  • Lists, headings, and paragraph margins are not globally removed so useful document structure and browser defaults are preserved until component styles intentionally replace them.

Spacing tokens

  • --space-xs — 0.25rem — very small internal spacing
  • --space-sm — 0.5rem — compact spacing
  • --space-md — 1rem — standard spacing
  • --space-lg — 1.5rem — larger component spacing
  • --space-xl — 2rem — section spacing
  • --space-2xl — 3rem — major section separation

Sizing and measure tokens

  • --measure-text — 65ch — maximum readable text measure
  • --container-max — 72rem — maximum page content width
  • --control-min-height — 2.75rem — minimum control height

Radius tokens

  • --radius-sm — 0.25rem — subtle rounding
  • --radius-md — 0.5rem — standard component rounding
  • --radius-lg — 1rem — prominent surfaces

Elevation tokens

  • --shadow-sm — low elevation for subtle surfaces
  • --shadow-md — stronger elevation for prominent surfaces

Typography tokens

  • --font-body — body and interface text
  • --font-display — headings and display text
  • --text-sm — metadata and compact labels
  • --text-base — standard body text
  • --text-lg — small headings
  • --text-xl — section headings
  • --text-2xl — major display heading
  • --line-body — body-text line height
  • --line-heading — heading line height

Usage guidance

Every text field and select is paired with a visible label. Related checkbox and radio controls are grouped with fieldset and legend elements. Controls inherit the shared type system and preserve visible keyboard focus.
